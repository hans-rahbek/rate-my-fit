# Rate My Fit — Beta 1

Discriminate like a pro. A browser-based incremental game about Fisher’s linear discriminant analysis.

Position and rotate a separation line, reveal your fit, and grow your population. Risk cards accumulate between rounds; research unlocks analytical aids.

## Publish with GitHub Pages

In Settings → Pages, choose Deploy from a branch, then main and / (root), and save.

No build step or dependencies are required. All files use relative paths.

## Saves and high scores

Progress and personal high scores are stored in each player's browser. Ten built-in benchmark scores are included; there is no shared online leaderboard. Moving to a different domain starts a separate browser save.
